# AI CFO Assistant MVP

Веб-приложение для финансового анализа и CFO-дайджеста с работой с CSV данными и локальным состоянием.

## Возможности

### 📊 CFO Дайджест
- Автоматическое выявление финансовых рисков
- Топ-3 "красные лампочки дня"
- Алерты по кассовым разрывам, просрочке AR, отклонениям от плана

### 💰 AR/AP Центр  
- Управление дебиторской и кредиторской задолженностью
- Анализ aging (старения задолженности)
- Автогенерация черновиков писем должникам
- Расчет DSO (Days Sales Outstanding)
- Экспорт данных в CSV

### 📈 План-Факт-Прогноз
- Сравнение плановых и фактических показателей
- Простое прогнозирование на основе трендов
- Анализ отклонений по периодам
- Инсайты и рекомендации

### 🏦 Финансовый эдвайзер
- Сравнение финансовых инструментов
- Расчет эффективной стоимости капитала
- Рекомендации в зависимости от цели финансирования
- Экспорт результатов сравнения

### 🤖 AI Ассистент
- Интеллектуальный чат-помощник для финансового анализа
- 6 категорий быстрых вопросов (денежный поток, риски, рентабельность, прогнозы, оптимизация, отчетность)
- Предустановленные экспертные ответы с практическими рекомендациями
- Интерактивные предложения для продолжения диалога

### 🎯 Сценарное моделирование
- **4 готовых сценария**: рост, оптимизация, кризис, расширение
- Интерактивная настройка параметров слайдерами
- Мгновенный расчет влияния на финансовые показатели
- Визуализация сравнения "текущее vs сценарий"
- Экспорт результатов моделирования

## Технический стек

- **Frontend**: React 18 + TypeScript
- **Стилизация**: Tailwind CSS
- **Роутинг**: React Router v6
- **Иконки**: Lucide React
- **Работа с CSV**: PapaParse
- **Даты**: date-fns
- **Состояние**: Локальный менеджер состояния с localStorage

## Установка и запуск

```bash
# Клонирование репозитория
git clone <repo-url>
cd ai-cfo-assistant

# Установка зависимостей
npm install
```



```bash
# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build
```

Приложение будет доступно по адресу http://localhost:3000

## Форматы данных

### sales.csv
```csv
doc_id,doc_date,counterparty_name,sku,qty,price,vat,amount,currency,project_id,paid_date
```

### purchases.csv  
```csv
doc_id,doc_date,supplier_name,sku,qty,price,vat,amount,currency,project_id,paid_date,expense_type
```

### ar_ap.csv
```csv
type,doc_id,doc_date,counterparty_name,amount,currency,due_date,paid_date
```

### cashflow.csv
```csv
date,category,subcat,amount,currency
```

### plan.csv
```csv
period,metric,amount,currency
```

## Использование

1. **Онбординг**: Настройте профиль и загрузите данные (CSV файлы или демо-данные)
2. **Dashboard**: Просматривайте CFO-дайджест и ключевые метрики
3. **AR/AP**: Анализируйте задолженности и генерируйте письма
4. **План-Факт**: Сравнивайте планы с фактом и изучайте прогнозы
5. **Эдвайзер**: Сравнивайте финансовые инструменты

## Особенности

- **Локальное состояние**: Все данные хранятся в браузере (localStorage)
- **Без серверной части**: Полностью frontend решение
- **CSV-ориентированность**: Работа с файлами в формате CSV
- **Демо-данные**: Встроенные демо-данные для быстрого старта
- **Валидация**: Проверка и очистка загружаемых данных
- **Экспорт**: Возможность выгрузки результатов анализа

## Ограничения MVP

- Нет интеграции с внешними системами (1С, банки)
- Работа только с одной валютой в рамках сессии
- Простые алгоритмы прогнозирования
- Нет полноценного чат-ИИ (только шаблонные подсказки)
- Графики представлены заглушками (требуется интеграция с chart.js/recharts)

## Деплой в интернет

### Способ 1: Netlify (Рекомендуется)

1. Создайте аккаунт на [netlify.com](https://netlify.com)
2. Перетащите папку `build` на страницу деплоя Netlify
3. Получите публичную ссылку на ваш сайт

### Способ 2: Vercel

```bash
npm install -g vercel
vercel --prod
```

### Способ 3: GitHub Pages

1. Загрузите проект на GitHub
2. Включите GitHub Pages в настройках репозитория
3. Выберите папку `build` как источник

### Локальный тест продакшн сборки

```bash
npm run build
npm install -g serve
serve -s build -p 5000
```

Приложение будет доступно по адресу http://localhost:5000
