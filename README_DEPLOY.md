# 🚀 Инструкция по развертыванию AI CFO Assistant

## Вариант 1: Локальный запуск

### Требования:
- Node.js версии 16 или выше
- npm или yarn

### Установка:
```bash
# 1. Распакуйте архив и перейдите в папку
cd ai-cfo-assistant

# 2. Установите зависимости
npm install

# 3. Запустите приложение
npm start

# 4. Откройте в браузере
# http://localhost:3000
```

## Вариант 2: Деплой в интернет

### Vercel (бесплатно, рекомендуется):
```bash
# 1. Зарегистрируйтесь на vercel.com
# 2. Установите Vercel CLI
npm install -g vercel

# 3. В папке проекта выполните
vercel

# 4. Следуйте инструкциям
# Получите публичную ссылку
```

### Netlify (альтернатива):
```bash
# 1. Соберите проект
npm run build

# 2. Перейдите на netlify.com
# 3. Перетащите папку build/ в браузер
# 4. Получите публичную ссылку
```

## Вариант 3: Docker

### Если у вас установлен Docker:
```bash
# Запуск одной командой
docker-compose up --build

# Приложение будет доступно на http://localhost:3000
```

## 📱 Установка как мобильное приложение

После открытия в браузере (Chrome/Safari):
1. Нажмите меню браузера (⋮)
2. Выберите "Добавить на главный экран"
3. Приложение установится как PWA

## 🔧 Настройки

- Все данные сохраняются локально в браузере
- Для сброса данных используйте кнопку "Начать заново"
- Поддерживаются форматы CSV для загрузки данных

## 📞 Поддержка

При возникновении проблем:
1. Убедитесь, что Node.js установлен корректно
2. Очистите кэш браузера
3. Попробуйте другой браузер
4. Проверьте, что порт 3000 свободен
